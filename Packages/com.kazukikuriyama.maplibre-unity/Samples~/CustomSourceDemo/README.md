# Custom Source Demo

Demonstrates `ICustomRasterSource` — the hook for serving raster tiles from a user-supplied backend (procedural generation, local files, custom HTTP, render-to-texture, etc.). Mirrors the MapLibre GL JS `type: "custom", dataType: "raster"` source.

## Behaviour

A procedural noise source overlays the basemap with translucent coloured tiles. Each tile is generated on demand from a deterministic value-noise function keyed by `(z, x, y)`, so panning back to a previously-visited area shows the same colours.

## What this proves

- The map drives `LoadTile(tileId, onSuccess, onError)` exactly the same way it drives the built-in URL fetcher. The custom source plugs into:
  - The 6-concurrent request queue.
  - The LRU tile cache (next visit short-circuits the loader).
  - Bounds and zoom range filtering.
  - The attribution control (the source's `Attribution` string is automatically rendered).
- No network, no external dependencies. Useful as a template for any custom tile-serving backend.

## Files

- `CustomSourceDemo.cs` — the demo MonoBehaviour and an inner `NoiseRasterSource : ICustomRasterSource` implementation.
- `CustomSourceDemoScene.unity` — minimal scene with `MapLibreMap` + `MapControlsOverlay` + this demo script.

## Required setup

Open the scene, press Play. Pan and zoom — each newly-visible tile is generated by the source on demand.

## Vector parity

The same pattern works for vector tiles: implement `ICustomVectorSource.LoadTile` to return PBF bytes (gzip optional — the source handles decompression). The bytes flow through the same parser pipeline used by HTTP-fetched vector tiles, so all expression/filter/paint features work unchanged.

```csharp
public class MyVectorSource : ICustomVectorSource
{
    public int MinZoom => 0;
    public int MaxZoom => 14;
    public double[] Bounds => null;
    public string Attribution => "...";

    public void LoadTile(CanonicalTileID tileId, Action<byte[]> onSuccess, Action<string> onError)
    {
        var bytes = File.ReadAllBytes($"./tiles/{tileId.Z}/{tileId.X}/{tileId.Y}.pbf");
        onSuccess(bytes);
    }

    public void UnloadTile(CanonicalTileID tileId) { }
}
```

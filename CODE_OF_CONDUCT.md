# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its
code of conduct. By participating in this project — through issues,
pull requests, discussions, or any other channel — you agree to abide
by its terms.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Summary

We pledge to make participation in our project a welcoming experience
for everyone, regardless of background or identity. The full text of
the Contributor Covenant lists the standards we expect, examples of
unacceptable behavior, and the enforcement responsibilities of project
maintainers.

The canonical, complete text lives at the link above; please read it.

## Reporting

If you experience or witness behavior that violates this code, report
it by opening a confidential issue on GitHub or by contacting the
maintainer at the email address listed on the GitHub profile of
[@KazukiKuriyama](https://github.com/KazukiKuriyama). Reports are
handled in confidence and reviewed promptly.

## Scope

This code applies in all project spaces (repository, issues, pull
requests, discussions) and in any public space when an individual is
representing the project.
